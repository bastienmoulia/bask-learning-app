# AGENTS.md

Bask is an Angular 22 + Firebase MVP for learning Basque, packaged for iOS with Capacitor. See [README.md](README.md) for product scope, Firebase setup, and TestFlight deployment.

## Commands

```bash
npm install
npm start                 # ng serve on http://localhost:4200
npm run build             # production build to dist/
npm test -- --watch=false # Vitest unit tests (jsdom)
npm run lint              # ESLint for .ts, .html, and .css
```

Cloud Functions live in `functions/` (Node 22, separate `package.json`, plain JavaScript in `functions/src/index.js`).

## Project layout

- `src/app/core/firebase/` — Firebase bootstrap helpers
- `src/app/core/services/` — auth, lessons, admin, learner progress, personalized practice
- `src/app/core/guards/` — route guards
- `src/app/features/<feature>/` — `home`, `lesson-player`, `sign-in`, `admin`
- `src/environments/environment.ts` — Firebase config placeholders; never commit secrets
- `firestore.rules`, `database.rules.json`, `firestore.indexes.json` — backend security and indexes
- `ios/` — Capacitor iOS project; `ios/App/App/public/` is generated by `npx cap sync`, do not edit

## Conventions

- Standalone components with `inject()`, signals (`signal`, `computed`), and `protected readonly` template members.
- Component and directive selectors use the `app` prefix (kebab-case elements, camelCase attributes).
- Each component uses separate `.ts`, `.html`, and `.css` files. Styles are plain CSS (no SCSS).
- Files are named without type suffixes (e.g. `auth.ts`, `home.ts`); specs sit next to the source as `*.spec.ts`.
- Prettier: single quotes, 100-column width, Angular parser for HTML.
- Templates must pass `angular-eslint` accessibility rules.

## Firebase and security

- Privileged operations (role changes, lesson publishing, AI lesson drafting) go through callable Cloud Functions that verify admin role server-side; never rely on client checks alone.
- Keep `firestore.rules` in sync with any data model change to `users/{uid}`, `lessons/{lessonId}`, or learner progress.
- Personalized practice depends on App Check and Firebase AI Logic; code must degrade gracefully when they are not configured.
- The starter lesson in `src/app/features/lesson-player/starter-lesson.ts` is the reviewed offline fallback; keep it working.

## Before finishing a change

Run `npm run lint` and `npm test -- --watch=false`, and add or update specs for changed services and components.
